---
Способности показаны значками на создании; наведите указатель на значок, чтобы увидеть название. В таблице — самые частые. Числа в скобках у разных созданий разные.

| Способность | Что делает |
|---|---|
| Летающий | Блокировать его могут только летающие создания. |
| Телохранитель (не может атаковать) | Стены: защищают, но никогда не атакуют. |
| Первый удар | Бьёт раньше противника — и в атаке, и в защите. |
| Регенерация (1–3) | Уничтоженное создание может вернуться, если заплатить указанную цену. |
| Кровожадный | Урон, оставшийся после уничтожения блокирующих, достаётся вражескому герою. |
| Вампир | Урон вражескому герою лечит хозяина. |
| Неутомимый | Не отдыхает после атаки. |
| Разбивает чары | Снимает чары с созданий, которых бьёт. |
| Создание не может подняться | Не поднимается само после отдыха. |
| Агрессивный | Обязан атаковать, когда может. |
| Эфирная защита | Не может быть целью заклинаний и способностей. |
| Неблокируемый | Его нельзя блокировать. |
| Готовность | Может действовать в тот же ход, когда вызван. |
| Увертливый | Блокировать его могут только стены. |
| Стражник | Атакует только вместе с созданием своей расы. |
| Ядовитый | Уничтожает создание, которому нанёс урон в бою. |
| Грабитель (1–3) | Нанеся урон вражескому герою, заставляет противника сбросить столько случайных заклинаний. |
| Способность к переходу в Бесцветный План | «Демиурги II»: создание может переходить в Бесцветный План, где не атакует и не подвергается атакам. |
| Глушение заклинаний | «Демиурги II»: мешает заклинаниям противника. |

Многие создания имеют и способности, которые применяются отдыхом или за эфир; их описания есть в самой игре. Как боевые способности действуют вместе, рассказано в статье [Атака и защита](attack-defence).
