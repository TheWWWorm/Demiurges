Главное меню — это меню оригинальной игры. Под его кнопками ремейк добавляет **Etherlords I** и **Etherlords II**: нажмите одну из них, чтобы переключить игру, или **Вики**, чтобы открыть эту вики. При следующем запуске открывается игра, в которую вы играли последней. Игра, которую вы ещё не добавили, подписана **not installed — add…** и открывает для неё [экран файлов игры](installing).

В вики откройте страницу создания, чтобы [посмотреть его атаки, гибель и другие анимации со звуком](creatures).

## Что есть в меню

- **«Демиурги»**: **Новая игра** (Дуэль, Кампания, Миссия), **Загрузить игру**, **Настройки**, **Зал славы** и **Авторы**. См. [Дуэль](duel).
- **«Демиурги II»**: **Одиночная игра** (Учебник, Дуэль, Кампания, Миссия), **Сетевая игра** ([дуэли по сети и за одним компьютером](duel)), **Настройки**, **Энциклопедия** и **Авторы**.

## Сохранения

Сохранение и загрузка используют оригинальные экраны. **F5** быстро сохраняет, а **F9** загружает быстрое сохранение — и на карте, и в бою. Сохранения оригинальных игр загрузить нельзя: у движка свои сохранения, отдельно для каждой игры.

## Где хранятся сохранения и настройки

| Система | Папка |
|---|---|
| Windows | `%APPDATA%\Godot\app_userdata\Etherlords Duel` |
| Linux | `~/.local/share/godot/app_userdata/Etherlords Duel` |
| macOS | `~/Library/Application Support/Godot/app_userdata/Etherlords Duel` |
| Браузер | хранилище браузера для этого сайта; очистка данных сайта удаляет их |
| Android | закрытое хранилище приложения; удаление приложения удаляет их |

Папка сохраняет прежнее название `Etherlords Duel`, чтобы старые сохранения продолжали работать.
